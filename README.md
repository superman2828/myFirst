Description: This is my first Spring Boot application for my Enterprise App Development course

How to Run:

1. On GitHub click Code → Download ZIP and extract the project, or use the Download ZIP button in the repository UI.

2. Open your IDE and choose "Open" or "Import Project" then select the extracted folder. Import as a Maven project if prompted.

3. Let the IDE resolve dependencies (it will download Maven artifacts automatically).

4. In the IDE's project explorer, open the main class: com.earlnt.myfirst.MyFirstApplication and click the Run/Play button provided by the IDE.

5. Open a browser to http://localhost:8080 and http://localhost:8080/about to view the app.
